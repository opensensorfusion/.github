# Open Sensor Fusion assets

Place Open Sensor Fusion organization branding assets in this directory.

Recommended filenames:

- `opensensorfusion-logo.svg` for a vector logo, if available.
- `opensensorfusion-logo.png` for a raster logo.

Keep source artwork and exported web assets small enough for GitHub rendering.
Do not place unrelated hardware photos in this directory; board-specific media
belongs in the relevant hardware repository.
